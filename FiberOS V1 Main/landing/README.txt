FiberOS — Landing page art
==========================
Drop transparent PNGs here and the home page loads them automatically as
parallax layers (no code changes needed). Back-to-front order:

  bg.png        Far background scene (table/room, soft greens).  ~2000 x 1400, can be full-bleed (no transparency needed).
  basket.png    The basket of green yarn balls.                  ~1400 x 1400, transparent background.
  yarnball.png  The single yarn ball that rolled out + its tail. ~1100 x 1100, transparent background.
  trail.png     (optional) Long yarn trail leading down to the   ~700 x 1700, transparent background.
                floor/buttons.

Tips
- Export as PNG-24 with transparency (except bg.png, which can be opaque).
- Keep the subject roughly centered; the engine adds mouse + scroll parallax.
- Higher res is fine; the browser scales down. Aim for crisp edges.
- Until these exist, the page shows a clearly-labeled placeholder scene.

Made with ChatGPT / Canva / Photopea all works great for these.
